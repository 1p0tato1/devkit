# Phase 1

## 🐙 GitHub CLI (gh)
- **What it does:** Permet de gérer l'intégralité du workflow GitHub (repos, issues, pull requests) directement depuis le terminal sans utiliser le navigateur.
- **One surprising thing:** On peut extraire des données ultra-précises au format JSON avec l'option `--json`, ce qui permet de scripter des automatisations complexes.
- **One use case I want to try:** Créer une commande qui ouvre automatiquement une Pull Request en draft dès que je crée une nouvelle branche de fonctionnalité.

## 🔍 fzf (Fuzzy Finder)
- **What it does:** Un filtre interactif en ligne de commande qui permet de chercher et de sélectionner des éléments dans n'importe quelle liste de manière instantanée.
- **One surprising thing:** Il peut afficher une fenêtre de "preview" pour voir le contenu d'un fichier ou d'un commit avant même de le sélectionner.
- **One use case I want to try:** L'intégrer à la commande de sélection d'issues pour choisir visuellement sur laquelle je veux travailler.

## 🦇 bat
- **What it does:** Un remplaçant de la commande `cat` qui ajoute la coloration syntaxique, les numéros de ligne et une intégration avec Git.
- **One surprising thing:** Il indique par des symboles dans la marge les lignes qui ont été ajoutées, modifiées ou supprimées par rapport au dernier commit Git.
- **One use case I want to try:** L'utiliser pour afficher les extraits de code que l'IA va analyser afin d'avoir un rendu lisible dans mon terminal.

## 📐 Delta
- **What it does:** Un afficheur de différences (diff) qui rend les modifications de code beaucoup plus lisibles avec des couleurs et un formatage professionnel.
- **One surprising thing:** Il est capable d'afficher les modifications côte à côte (side-by-side) directement dans le terminal, comme dans VS Code.
- **One use case I want to try:** Remplacer le `git diff` standard par Delta pour relire mon code plus efficacement avant de valider mes changements.

## 🤖 AI CLI Tools (Copilot & Gemini)
- **What it does:** Des interfaces en ligne de commande pour utiliser les modèles d'IA afin de générer du code, expliquer des erreurs ou suggérer des commandes shell.
- **One surprising thing:** On peut rediriger (piper) le contenu de n'importe quel fichier ou erreur directement dans l'IA pour obtenir un diagnostic immédiat.
- **One use case I want to try:** Créer un "Code Reviewer" automatique qui analyse mes changements et me suggère des améliorations avant que je ne pousse mon code.
